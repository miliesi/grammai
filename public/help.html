Need a hand?

“Command not found”

Open a new Terminal window after installing Node.js or your CLI. Follow the provider’s official instructions to add it to PATH if necessary. Then run the helper installation command again.

“Local helper is not connected”

Download the current helper and run step 3 from this page. Its command contains the ID of the extension you are using, so a Store installation and a development installation can need different registrations.

The CLI is found, but rewrites fail

Sign in again using the command in step 2 and check your provider’s account limits. grammai uses that account; it does not include an AI subscription. If an optional model is set in AI settings, clear it to use the CLI’s default for rewrites.

I’m on Windows or Linux
