# Contributing to grammai

Thanks for helping make writing assistance easier to use.

## Start locally

```sh
npm ci
npm run typecheck
npm test
npm run build
```

Use Node.js 22 or newer, then load `dist` through your browser's extension management screen. Grammar checking works without the AI helper. See [development reference](docs/development.md) for the code layout and browser tests.

## Report a bug

Use the [issue tracker](https://github.com/zilvestro/grammai/issues), or email grammai@zaapp.io. Include the browser/version, website/editor, expected behavior and a small reproducible sample. Anonymize text and screenshots. Never include passwords, API keys, provider tokens or private drafts.

For editing bugs, tell us whether typing, Backspace, selecting/deleting all text, and undo still work after the action. For grammar bugs, include a correct counterexample so a narrow fix does not introduce a new false positive.

## Send a change

Fork [zilvestro/grammai](https://github.com/zilvestro/grammai), create a branch, commit your change and open a pull request against `main`. For larger features, discuss the scope in an issue first.

Keep changes focused. Explain the user-visible problem, the resulting behavior and how you checked it. Run type checking and relevant checks for the changed path. Add a regression test for behavioral bugs; visual spacing and copy changes usually need a visual check rather than a test that repeats the implementation.

Preserve native selection, editor formatting, keyboard access, appearance preferences and stale-result guards. Keep normal checking local. Never add analytics, remote text processing or new permissions without making the proposed behavior explicit.

Run Prettier on changed supported files. Avoid generated output, browser profiles, research captures, credentials and personal configuration in a contribution. `src/generated/dictionaries.ts` is regenerated by the build.
